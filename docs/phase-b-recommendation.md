# Recommended Phase B review scope

1. Content CRUD and 100-row/day CSV imports with preview, rejection reports, conservative normalization, and client-scoped deduplication.
2. Platform capability seeding and account/content permission verification workflows.
3. SSRF-safe technical inspection for HTTP, redirects, canonical, robots, and noindex signals.
4. Evidence freshness and deterministic status derivation.
5. Durable PostgreSQL job execution with idempotency, leases, capped retries, and per-origin throttling.

Paid ranking providers, publication automation, promotion submission, and private-dashboard scraping should remain outside Phase B unless separately approved.
